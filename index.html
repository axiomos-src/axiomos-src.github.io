AxiomOS

An open-source operating system, built from scratch.

⚠️ Early Development Warning

AxiomOS is still in an early development version. Running on real hardware may cause data loss. Please use virtual machines only.

UEFI Boot

UEFI-first bootloader, GOP graphics, ACPI support, boots directly to kernel.elf.

Aurora GUI

Custom desktop compositor & widget system, independent design, not a clone of Windows.

HVCI Integrity

Software code integrity checker, kernel memory protection & violation statistics.

C / NASM / Rust

Main kernel written in C, assembly for low-level entry, Rust for selected subsystems.
